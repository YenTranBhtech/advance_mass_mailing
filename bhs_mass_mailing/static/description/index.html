Installation

1. Install bhs_mass_mailing module in Odoo.

2. Restart Odoo to apply the module changes.

Configuration

Configure Amazon SES in Settings → Technical → Email → Outgoing Mail Servers. The module will then synchronize suppression records and optimize mailing contacts.

1. What is Amazon SES, and why does this module integrate with it?

Amazon Simple Email Service (SES) is Amazon Web Services' cloud email platform for sending transactional and marketing emails. This module integrates with Amazon SES to automatically synchronize bounced and complaint email records, helping Odoo maintain cleaner mailing lists and improve email deliverability.

2. What are Bounce and Complaint emails?

A Bounce occurs when an email cannot be delivered to the recipient, while a Complaint is generated when a recipient marks your email as spam. Both negatively affect your sender reputation, so identifying and removing these addresses is essential for maintaining successful email campaigns.

3. How does the module prevent duplicate mailing contacts?

The module validates email uniqueness before creating mailing contacts. When an existing email is imported again, it updates the contact's mailing list assignment instead of creating a duplicate record, while also providing tools to remove existing duplicates.

4. How does the module improve email deliverability?

By synchronizing Amazon SES suppression data, removing invalid contacts, preventing duplicate emails, maintaining clean mailing lists, and blocking restricted domains, the module helps improve sender reputation and increases the likelihood that marketing emails successfully reach recipients.
